# Descripción del Sistema 

Este sistema digitaliza una solución eficaz para la problemática existente en cualquier negocio físico (en este caso, orientado a una ferretería): la necesidad de organización y de mantener registros limpios de información relevante y necesaria. 

El sistema entrelaza información mediante tablas requeridas según las necesidades de almacenamiento del negocio, siendo en este caso **15 tablas en total**. 

La base de datos contiene automatizaciones de procesos importantes, como:
* Actualización de stock
* Facturación
* Entre otros procesos clave

También cuenta con tablas de tipo catálogo, transaccionales y vistas, las cuales son esenciales para lograr un sistema muy completo con un tráfico de datos moderado.
